## ⚙️ Installation & Development

This portfolio is built with **Next.js 15**, **Tailwind CSS**, and **TypeScript**.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ManuelCobos24/manuelcobos-dev.git
   ```
2. **Install dependencies:**
   ```bash
   pnpm install
   ```
3. **Run the development server:**
   ```bash
   pnpm dev
   ```
4. **Build for production:**
   ```bash
   pnpm build
   ```
