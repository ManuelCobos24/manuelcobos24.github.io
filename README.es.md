## ⚙️ Instalación y Desarrollo

Este portfolio está construido con **Next.js 15**, **Tailwind CSS** y **TypeScript**.

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/ManuelCobos24/manuelcobos-dev.git
   ```
2. **Instalar dependencias:**
   ```bash
   pnpm install
   ```
3. **Ejecutar servidor de desarrollo:**
   ```bash
   pnpm dev
   ```
4. **Construir para producción:**
   ```bash
   pnpm build
   ```
